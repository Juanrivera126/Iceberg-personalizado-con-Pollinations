# Iceberg personalizado con Pollinations

Aplicación web interactiva que genera "icebergs" temáticos con múltiples niveles de profundidad utilizando inteligencia artificial.

[Demo](https://juanrivera126.github.io/Iceberg-personalizado-con-Pollinations/ejemplos/Iceberg_IoT.html)

## Características

- **Multiidioma**: Interfaz disponible en Español 🇪🇸, Inglés 🇬🇧 y Francés 🇫🇷
- **Generación de contenido con IA**: Utiliza modelos de lenguaje avanzados (Gemini, GPT, DeepSeek, Claude, Perplexity) para generar contenido temático
- **Generación de imágenes**: Crea imágenes únicas para cada entrada usando modelos como Flux, Z Image, GPT Image, entre otros
- **5 niveles de profundidad**: Desde contenido superficial hasta información oscura y poco conocida
- **Estilos visuales personalizables**: 11 estilos artísticos diferentes (Cinemático, Horror Análogo, Cyberpunk, etc.)
- **Paletas de colores dinámicas**: 8 temas visuales que cambian la apariencia completa
- **Exportación HTML**: Descarga tu iceberg completo como archivo HTML independiente
- **Integración con Pollinations.ai**: Soporte para API keys personalizadas (BYOP - Bring Your Own Pollinations)

## Estructura de Niveles

1. **Nivel 1: La Superficie** - Cultura pop, memes, hechos oficiales
2. **Nivel 2: Aguas Poco Profundas** - Datos curiosos, trivia técnica
3. **Nivel 3: La Zona de Penumbra** - Rumores, conspiraciones leves
4. **Nivel 4: El Abismo** - Archivos perdidos, incidentes oscuros
5. **Nivel 5: El Vacío Insondable** - Horror cósmico, metafísica

## Uso

1. Abre `index.html` en tu navegador
2. Selecciona tu idioma preferido en el selector superior derecho (🇪🇸 🇬🇧 🇫🇷)
3. Ingresa un tema central (ej: "Teoría de Internet Muerta", "Biología Marina")
4. (Opcional) Ingresa tu API Key de Pollinations.ai o haz clic en "🔑 Obtener" para vincular una
5. Selecciona:
   - Estilo visual para las imágenes
   - Modelo de IA para texto
   - Modelo de IA para imágenes
   - Profundidad (3-5 niveles)
6. Haz clic en "🔮 Generar Iceberg"
7. Explora cada entrada haciendo clic en los títulos
8. Descarga tu iceberg con el botón "📥 Descargar Iceberg HTML"

## Idiomas Soportados

La aplicación está completamente traducida a:
- **Español**: Interfaz completa, nombres de niveles y descripciones
- **English**: Full interface, level names and descriptions
- **Français**: Interface complète, noms de niveaux et descriptions

El idioma seleccionado se guarda automáticamente en el navegador para futuras visitas.

## Características Técnicas

- **Sin dependencias externas**: Todo el código está contenido en archivos HTML independientes
- **Responsive**: Funciona en dispositivos móviles y de escritorio
- **Regeneración de imágenes**: Cada imagen puede regenerarse individualmente
- **Modal de zoom**: Haz clic en cualquier imagen para verla en pantalla completa
- **Animaciones suaves**: Transiciones y efectos visuales pulidos
